## 📥 Step 1: Install Ollama

### Windows Installation:

1. **Download Ollama**:
   - Go to: https://ollama.com/download
   - Click "Download for Windows"
   - Run the installer: `OllamaSetup.exe`

2. **Verify Installation**:
   ```powershell
   # Open new PowerShell window (IMPORTANT!)
   ollama --version
   ```
   
   Expected output:
   ```
   ollama version 0.1.X
   ```

---

## 🚀 Step 2: Install LLaMA 3 Model

### Option A: LLaMA 3 8B (Recommended for Testing)
```powershell
# Start Ollama server (in one terminal)
ollama serve

# In ANOTHER PowerShell window, download model
ollama pull llama3
```

**Download size**: ~4.7 GB  
**RAM needed**: 8 GB  
**Speed**: Fast responses (~2-5 seconds)

### Option B: LLaMA 3.1 8B (Newer version)
```powershell
ollama pull llama3.1
```

**Download size**: ~4.7 GB  
**RAM needed**: 8 GB  
**Better reasoning**, slightly slower

### Option C: LLaMA 3 70B (High Quality - if you have powerful PC)
```powershell
ollama pull llama3:70b
```

**Download size**: ~40 GB  
**RAM needed**: 64 GB  
**Best quality**, slower (~10-20 seconds)

**💡 Recommendation**: Start with `llama3` or `llama3.1` (8B version)

## 🔧 Troubleshooting

### Issue 1: "ollama: command not found"
**Solution**: Restart PowerShell after installation, or use full path:
```powershell
& "C:\Users\<YourName>\AppData\Local\Programs\Ollama\ollama.exe" --version
```

### Issue 2: Ollama server not responding
**Solution**: Make sure `ollama serve` is running in another terminal:
```powershell
# Terminal 1 (keep running):
ollama serve

# Terminal 2 (your work):
python main.py --interactive
```

### Issue 3: Model not found
**Solution**: Pull the model first:
```powershell
ollama pull llama3
```

### Issue 4: Out of memory
**Solution**: Use smaller model or close other applications:
```powershell
# Use quantized version (smaller)
ollama pull llama3:7b-q4_0
```

### Issue 5: DSPy not connecting to Ollama
**Solution**: Configure DSPy endpoint in code (I'll show you if needed)
